# Web and shared UI

- [Browser evaluate under tsx](browser-evaluate-tsx.md) — nested named callbacks can reference a Node-only name-preservation helper inside the browser.
- [Web central unit conversion](web-central-unit-conversion.md) — item-owned relationships, one base, exact conversion, and immutable historical document factors; global factors are not item relationships.
- [Zod datetime strict rejects +00:00](zod-datetime-offset.md) — chrono `to_rfc3339()` emits offset form, never `Z`; any zod schema validating a Rust-produced timestamp MUST use `{offset:true}` or it 400s.
- Item cost & rep lock — [Item-master cost write-back](item-master-cost-writeback.md) — stock inflows only update stock_balance.avg_cost; items.cost_price (الأصناف grid تكلفة) needs an explicit refreshItemCost write-back per inflow path or it stays stale at 0.00. | [Sales-rep picker lock vs manager freedom](sales-rep-manager-freedom.md) — admin/superadmin must be exempt from rep lock in TWO places: /me/current 404 (UI unlock) AND create auto-attribution (else explicit-empty rep still re-tags linked rep).
- Date inputs — [DateField adapter](date-field-adapter.md) + [Hijri](hijri-date-field-calendar.md): zatca-invoicing uses DateField→SmartDateInput (DD/MM/YYYY, ISO stored) everywhere, never native type=date (garbled Hijri on Saudi devices); Hijri is one Umm al-Qura popover bound to the Gregorian ISO field, never a separate column. | [Date field traps](native-date-input-clamp.md) — native `type=date` silently drops impossible day+month combos (no change event); `toISOString()` default is a day behind in UTC+3; use SmartDateInput (DD/MM/YYYY).
- [Cascade picker rehydration](cascade-picker-rehydration.md) — main→leaf picker must derive parent deterministically from leaf value (not prev||), but never reset parent on empty value (parent-pick clears the leaf on purpose).
- [Aggregate view composite key](aggregate-view-composite-key.md) — multi-table "show all" grids must key selection/bulk/busy/testid by module:id, not numeric id; id collides across tables → bulk hits wrong doc.
- RTL styling — [TableHead alignment](rtl-tablehead-text-start.md) + [padding conflict](rtl-physical-logical-padding-conflict.md): use text-start/text-end logical classes in table primitives; never mix px-*/pl-* with ps-*/pe-* on direction-aware controls (physical wins, collapses icon gutters).
- [Item Usage Control](item-usage-control.md) — per-item×per-screen routing rules; absence=default "allowed", persist ONLY non-default rows (drop allowed even with a reason) or getScreenModesForItems diverges from getItemUsageControls.
- [List-grid COLUMNS memo dep trap](list-grid-columns-memo-dep.md) — unmemoized column-descriptor arrays in a filtered-useMemo's deps refilter huge grids every render (reads as a hang); memoize COLUMNS+totals, defer search.
- [Large registers must stay paged](large-register-no-show-all.md) — server-paged high-volume grids must not honor legacy “all”; normalize saved 0 values before the first request and cap the API page size.
- [Item-group category routing](item-group-category-routing.md) — categoryType asset/expense = no stock + debit group acct (mirrors service-item pattern); inventoryApi prefixes /api/inventory — never fetch /api/item-groups.
