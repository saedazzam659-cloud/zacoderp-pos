---
name: Clarify before changing the app
description: Keep discussion separate from authorization to edit, publish, or roll back the project.
---

Treat exploratory questions as questions. Do not edit, publish, or roll back unless the user explicitly asks.

**Why:** The user clarified that they were explaining the reason for a request, not asking for an immediate recovery action. Confirm intent before taking changes that affect the project or deployment.

**How to apply:** For ambiguous mentions of publishing, restoring, or rollback, answer the question first and ask before changing files or triggering platform actions.
