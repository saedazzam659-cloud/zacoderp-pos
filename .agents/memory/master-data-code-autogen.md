---
name: Master-data code auto-generation
description: Blank code on create is generated SERVER-side via nextEntityCode; client must never mint codes.
---
Blank `code` on master-data create (items ITM, item-groups GRP, units UNT, brands BRD, warehouses WH, customer-groups CG, supplier-groups SG) is auto-generated by the API via `api-server/src/lib/nextEntityCode.ts` (per-company max trailing number + 1, `PREFIX-0001`).

**Why:** Warehouses.tsx used to mint codes client-side (dominant-prefix heuristic) → two generators drifting. Server is the single authority; UI sends blank + shows "اتركه فارغاً" hint, forms only require nameAr.

**How to apply:** any NEW entity with a code field: require name only, generate through nextEntityCode against the company-scoped rows already loaded for the dup check, and run the generated code through the SAME dup check. Caveat: no `(companyId, code)` DB unique constraints on these tables — the dup check is app-level only, so concurrent blank creates can theoretically collide (accepted risk; if it bites, add a unique index + retry-on-conflict).
