name: Module-aware user guide
description: Product requirement for help content that adapts to each company's enabled ERP modules.
---

The operating guide should be organized by module and show each company only the chapters for modules enabled in that company.

**Why:** The user asked for the guide to match module activation within each company rather than present an irrelevant, fixed manual.

**How to apply:** Resolve the current company's enabled modules before rendering module-specific guide sections; keep general instructions available independently.
