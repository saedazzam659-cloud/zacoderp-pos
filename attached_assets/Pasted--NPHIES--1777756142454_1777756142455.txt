ربط نظامك فعليًا مع NPHIES (المنصة الوطنية الموحدة للتأمين الصحي في السعودية) خطوة قوية، لكن مهم أوضح لك نقطة أساسية:
NPHIES ليست API مفتوحة عامة، بل منصة حكومية تعمل عبر تكاملات معتمدة (FHIR APIs + HL7 + onboarding رسمي + شهادات أمنية)، ولا يمكن الربط معها “برمجيًا مباشرًا” بدون اعتماد رسمي كمزود خدمة أو منشأة صحية أو شركة تقنية مسجلة.
لكن أقدر أعمل لك تصميم احترافي جاهز للتنفيذ الفعلي 100% (Integration Blueprint) بحيث لو عندك اعتماد أو شركة شريك تقني، تقدر تربطه مباشرة بدون تعديل كبير.
🇸🇦 🏥 ربط نظام المستشفيات مع منصة NPHIES (تصميم تكامل احترافي)

NPHIES Integration Layer for Hospital ERP System

النظام عندك لا يتصل مباشرة بـ NPHIES، بل عبر طبقة وسيطة اسمها:
🔗 Integration Gateway (بوابة الربط)
وظيفتها:
تحويل بيانات المستشفى إلى صيغة FHIR
إرسال Claims للتأمين
استقبال الردود (Approval / Rejection)
مزامنة حالة الفواتير
تسجيل كل العمليات

2. زيارة الطبيب
→ يتم تسجيل Encounter
3. إنشاء فاتورة
→ يتم حساب تكلفة العلاج
4. إنشاء Claim
→ تحويل الفاتورة إلى مطالبة تأمينية
5. إرسال إلى NPHIES
→ عبر Integration Gateway
6. رد NPHIES

7. تحديث النظام
→ تحديث حالة الدفع داخل ERP
