تطوير موديل الكنترول الأكاديمي وربطه ببوابة ولي الأمر

أكمل موديل المدارس الحالي بإضافة موديل الكنترول الأكاديمي الخاص بالمواد والدرجات والتقييمات والنتائج، وربطه مباشرة ببوابة ولي الأمر الموجودة حاليًا، مع الحفاظ الكامل على جميع الوظائف والبيانات الحالية وعدم إنشاء أي شاشات أو بيانات مكررة.

1. إعداد المواد الدراسية

- تعريف المواد وربطها بالمرحلة والصف والفصل الدراسي.
- تحديد الدرجة العظمى والصغرى لكل مادة.
- تحديد نوع المادة حسب إعدادات المدرسة.
- ربط المادة بالمعلم والشعبة.

2. درجات الطلاب

إضافة إدارة درجات الطلاب حسب:

- العام الدراسي.
- الفصل الدراسي.
- المرحلة والصف.
- الشعبة.
- المادة.
- الطالب.

وتشمل:

- درجات التقييمات.
- أعمال السنة.
- امتحانات الشهر.
- درجات نصف السنة.
- درجات نهاية السنة.
- الدرجة النهائية.
- التقدير والنسبة.
- حالة الطالب: ناجح / راسب / دور ثانٍ حسب نظام المدرسة.

3. التقييم اليومي

إضافة التقييم اليومي للطالب مرتبطًا بالطالب والمادة والمعلم والتاريخ، ويشمل حسب إعدادات المدرسة:

- الحضور والانضباط.
- المشاركة.
- الواجب.
- النشاط والتفاعل.
- السلوك.
- تقييم المعلم.
- الملاحظات.

مع إمكانية تحويل التقييمات إلى درجات عند اعتمادها ضمن نظام احتساب النتيجة.

4. التقارير الدورية

يتم إنشاء سجل تراكمي للطالب يسمح بعرض:

- التقرير الأسبوعي: ملخص درجات وتقييمات الطالب خلال الأسبوع.
- التقرير الشهري: مستوى الطالب وتقييماته خلال الشهر.
- امتحانات الشهر ونتائجها.
- نتيجة نصف السنة.
- نتيجة آخر السنة.
- إجمالي الدرجات والنسبة والتقدير.
- المواد التي تحتاج إلى متابعة.
- ملاحظات المعلمين.

5. بوابة ولي الأمر

ربط جميع النتائج والتقييمات ببوابة ولي الأمر الموجودة حاليًا.

بعد دخول ولي الأمر إلى حسابه يستطيع رؤية أبنائه المسجلين لديه، ثم اختيار الطالب ومتابعة:

لوحة الطالب:

- الحضور والغياب.
- التقييم اليومي.
- التقرير الأسبوعي.
- التقرير الشهري.
- درجات امتحانات الشهر.
- درجات المواد.
- نتيجة نصف السنة.
- نتيجة آخر السنة.
- النسبة والتقدير.
- ملاحظات المعلمين.
- مستوى الطالب وتطور أدائه.

مع عرض البيانات بشكل واضح وسهل على الهاتف والكمبيوتر.

6. حماية واعتماد النتائج

- لا تظهر النتيجة النهائية لولي الأمر إلا بعد اعتمادها من الكنترول.
- التقييمات اليومية يمكن عرضها حسب إعدادات المدرسة.
- بعد اعتماد نتائج نصف السنة أو آخر السنة يتم منع التعديل عليها إلا بصلاحية إدارية.
- تسجيل كل تعديل على الدرجات والنتائج.
- ولي الأمر يستطيع الاطلاع فقط ولا يستطيع تعديل أي بيانات أكاديمية.

7. التقارير داخل الإدارة

إضافة تقارير للمدرسة:

- كشف درجات الطلاب.
- نتيجة الصف والشعبة.
- نتيجة كل مادة.
- تقرير التقييم اليومي.
- التقرير الأسبوعي والشهري.
- نتائج امتحانات الشهر.
- نتائج نصف السنة.
- نتائج آخر السنة.
- تقرير مستوى الطالب وتطور أدائه.

مهم جدًا: قبل التنفيذ افحص النظام الحالي وقاعدة البيانات وبوابة ولي الأمر الموجودة بالفعل. إذا كانت أي وظيفة أو بيانات موجودة، يتم تطويرها وربطها بدلًا من إنشاء نسخة جديدة منها. ممنوع تكرار البيانات أو كسر أي وظيفة أو صلاحية أو علاقة موجودة حاليًا.
