طوّر شاشة المستخلص الحالية لتصبح نظام مستخلصات مقاولات احترافي وقوي، مع الحفاظ الكامل على جميع الحقول والقيم والربط الحالي.

مهم جدًا:
- جميع القيم الموجودة حاليًا والتي يتم جلبها تلقائيًا من العقد والمستخلصات السابقة تظل كما هي.
- لا تنشئ حقولًا مكررة.
- لا تعيد إدخال أي قيمة موجودة تلقائيًا.
- أضف فقط الوظائف الناقصة.

أضف الوظائف التالية:

1. بنود المستخلص
- ربط المستخلص ببنود العقد وأوامر التغيير.
- عرض الكمية السابقة، الحالية، والتراكمية.
- عرض قيمة الأعمال السابقة، الحالية، والتراكمية.
- منع تجاوز الكميات أو قيمة العقد إلا بصلاحية واعتماد.

2. الاستقطاعات
إضافة قسم مرن للاستقطاعات يشمل:
- دفعة مقدمة
- ضمان أعمال / Retention
- غرامات وجزاءات
- خصم مواد أو عهد
- خصومات تسويات
- خصومات أخرى
مع إمكانية تحديد النسبة أو القيمة، السبب، المرجع، والملاحظات.

3. الغرامات
الغرامة تكون بندًا مستقلًا ولا تقلل قيمة الأعمال.
تسجيل:
- نوع الغرامة
- السبب
- قيمة الغرامة
- تاريخها
- رقم القرار/المرجع
- الملاحظات
مع ربطها بالمستخلص والحساب المحاسبي المناسب.

4. المستخلص التراكمي
إظهار:
- قيمة العقد الأصلية
- أوامر التغيير
- القيمة المعدلة
- السابق
- الحالي
- التراكمي
- المتبقي
- نسبة الإنجاز التراكمية.

5. الحساب المالي
يتم احتساب صافي المستخلص تلقائيًا من البيانات الموجودة:
إجمالي الأعمال
→ الاستقطاعات
→ صافي قبل الضريبة
→ الضرائب
→ صافي المستحق.

6. الدفعات
ربط المستخلص بالدفعات الفعلية:
- المدفوع سابقًا
- المدفوع الحالي
- المتبقي
- حالة السداد
مع منع تكرار احتساب أي دفعة.

7. المستندات
إضافة مرفقات المستخلص:
- فاتورة
- شهادة إنجاز
- محضر استلام
- مستند غرامة
- مستندات أخرى
مع حفظها وربطها بالمستخلص.

8. الاعتماد
تطبيق دورة احترافية:
Draft
→ Submitted
→ Under Review
→ Approved
→ Posted
→ Partially Paid / Paid
→ Rejected

مع تسجيل المستخدم والتاريخ والوقت لكل إجراء.

9. المحاسبة
عند الترحيل:
- إنشاء القيود المحاسبية تلقائيًا.
- ربط المقاول.
- ربط الأعمال.
- ربط الخصومات.
- ربط الغرامات.
- ربط الضرائب.
- عدم إنشاء قيد مكرر.

10. الرقابة
إضافة Validation قوي يمنع:
- تجاوز قيمة العقد.
- تجاوز الكميات المعتمدة.
- تكرار المستخلص.
- تكرار الدفعات.
- تكرار الخصومات.
- اعتماد مستخلص غير مكتمل.
- تعديل مستخلص مرحّل بدون صلاحية.

11. التقارير
إضافة تقارير المقاولات الأساسية:
- كشف مستخلصات المقاول.
- إجمالي المستخلصات.
- المستخلصات السابقة والحالية والتراكمية.
- إجمالي الخصومات.
- إجمالي الغرامات.
- إجمالي الضمانات.
- إجمالي المدفوعات.
- الرصيد المستحق.
- نسبة إنجاز العقد.
- المتبقي من العقد.

12. الصلاحيات
تطبيق صلاحيات منفصلة على:
- إنشاء
- تعديل
- مراجعة
- اعتماد
- ترحيل
- دفع
- إلغاء
- تعديل المستخلص المرحّل.

اجعل النظام يعتمد بالكامل على البيانات الحالية الموجودة في ERP، ويستخدم العلاقات والجداول الحالية بدل إنشاء بيانات مكررة.

الهدف: تحويل شاشة المستخلص الحالية إلى نظام مقاولات احترافي قابل لإدارة المشاريع والمقاولين والمستخلصات والخصومات والغرامات والدفعات والتسويات بشكل متكامل، بدون كسر أي جزء من النظام الحالي.
