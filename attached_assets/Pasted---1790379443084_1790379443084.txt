تعديل الربط التلقائي بين المشروع والمناقصة وخطاب الضمان

- بما أن المشروع يتم إنشاؤه أولًا، ويتم إنشاء المناقصة من داخل المشروع، يجب الحفاظ على المشروع كسجل أساسي، مع حفظ الربط التلقائي بين المشروع والمناقصة.
- عند إنشاء المناقصة من داخل المشروع، يتم ربط المناقصة بالمشروع تلقائيًا، وتظهر القيمة التقديرية للمناقصة في المناقصة مع إمكانية إدخالها أو تعديلها حسب الصلاحيات.
- لا يتم طلب إعادة إدخال قيمة المناقصة يدويًا في المشروع؛ بل عند الحاجة لعرض قيمة المناقصة داخل المشروع يتم جلبها تلقائيًا من المناقصة المرتبطة.
- عند إنشاء خطاب ضمان مرتبط بالمناقصة، يتم جلب قيمة المناقصة تلقائيًا واستخدامها كأساس لحساب قيمة الضمان حسب نوع الضمان ونسبته.
- عند وجود ترسية أو عقد مرتبط بالمناقصة، يتم استخدام قيمة الترسية أو قيمة العقد كأساس للضمانات التي تعتمد على قيمة العقد، مثل:
  - الضمان النهائي.
  - ضمان الصيانة.
- بالنسبة لضمان الدفعة المقدمة، تكون القيمة الأساسية هي قيمة الدفعة المقدمة المرتبطة.
- القيم التي يتم جلبها أو حسابها تلقائيًا تكون غير قابلة للتعديل للمستخدم العادي، ولا يسمح بتعديلها إلا بصلاحية خاصة.
- يتم تسجيل أي تعديل يدوي على القيم التلقائية في سجل التدقيق Audit Log مع المستخدم والتاريخ والقيمة السابقة والقيمة الجديدة.

الحقول المطلوبة لاستكمال دورة خطابات الضمان

- مصدر الضمان: مناقصة / ترسية / عقد / مشروع / دفعة مقدمة.
- المناقصة المرتبطة.
- الترسية المرتبطة.
- العقد المرتبط.
- المشروع المرتبط.
- نوع الضمان: ابتدائي / نهائي / دفعة مقدمة / صيانة / أخرى.
- القيمة الأساسية للضمان، ويتم جلبها تلقائيًا من المصدر المرتبط.
- نسبة الضمان %.
- قيمة خطاب الضمان، وتحسب تلقائيًا.
- رقم خطاب الضمان.
- البنك المصدر.
- المستفيد.
- تاريخ الإصدار.
- تاريخ الانتهاء.
- تاريخ التمديد إن وجد.
- قيمة الرسوم البنكية.
- حالة الخطاب: ساري / منتهي / ممدد / مفرج عنه / ملغى.
- سبب أو شرط الإفراج أو الإلغاء.
- تاريخ الإفراج الفعلي.
- المرفقات.
- الملاحظات.

قاعدة الربط الأساسية

المشروع → المناقصة → الترسية → العقد → المشروع/المستخلصات والدفعات → خطابات الضمان

مع السماح لخطاب الضمان بالارتباط بالمصدر المناسب حسب نوعه، وعدم إجبار جميع الضمانات على نفس مصدر القيمة.

مهم جدًا

- عدم إنشاء أي شاشة جديدة إذا كانت الوظيفة موجودة حاليًا.
- عدم إنشاء وظائف أو حقول مكررة.
- عدم تغيير أو كسر أي Workflow أو وظيفة موجودة حاليًا.
- الحفاظ على شاشة خطابات الضمان الحالية وتصميمها وصلاحياتها ومرفقاتها وسجل التدقيق.
- المطلوب هو إضافة الربط والحقول والمنطق التلقائي فقط فوق النظام الحالي.
- يجب الحفاظ على جميع البيانات والسجلات الحالية وعدم التأثير عليها.
