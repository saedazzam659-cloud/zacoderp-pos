شرط أساسي وحاسم: الحفاظ على بيانات وتقارير النظام الحالي

يجب تنفيذ جميع التعديلات الجديدة كطبقة UI / Theme / Configuration فقط، مع عدم المساس بأي بيانات أو منطق أو نتائج خاصة بالتقارير الحالية.

ممنوع تمامًا:

- حذف أو تعديل أي بيانات مرتبطة بأي تقرير.
- حذف أي تقرير موجود حاليًا.
- تغيير استعلامات التقارير أو منطق احتسابها بدون ضرورة.
- تغيير نتائج التقارير الحالية.
- تغيير الفلاتر الحالية للتقارير.
- تغيير صلاحيات الوصول للتقارير.
- تغيير بيانات التاريخ أو الأرصدة أو الحركات التي تعتمد عليها التقارير.
- نقل أو إعادة إنشاء بيانات التقارير بطريقة قد تسبب فقدان أو تكرار البيانات.
- إنشاء نسخة مكررة من التقرير بدل استخدام التقرير الحالي.

آلية العمل

عند تفعيل واجهة التقارير الموحدة للوكيل:

يتم تغيير طريقة عرض والوصول إلى التقارير فقط.

مثال:

بدل ظهور:

تقرير حركة الأصناف
تقرير أرصدة المخزون
تقرير الجرد
تقرير التشغيلات
تقرير الأصناف الراكدة

كرابط منفصل لكل تقرير،

يظهر:

📊 تقارير المخازن

ومن خلالها يتم اختيار التقرير من البحث أو Combo Box، ثم يتم فتح نفس التقرير الموجود حاليًا بنفس البيانات والفلاتر والمنطق والنتائج.

الرجوع للوضع الافتراضي

يجب أن يكون التغيير قابلًا للعكس بالكامل.

إذا قام SuperAdmin بإلغاء تفعيل:

التصميم المخصص / واجهة التقارير الموحدة

للوكيل، يجب أن يعود الوكيل تلقائيًا إلى نفس شكل النظام السابق قبل التفعيل.

أي أن:

- القوائم تعود كما كانت.
- روابط التقارير تعود كما كانت.
- التقارير تظهر بنفس أماكنها السابقة.
- نفس الفلاتر تعمل.
- نفس البيانات تظهر.
- نفس الصلاحيات تعمل.
- نفس نتائج التقارير تظهر.
- لا يتم فقد أي ترتيب أو بيانات أو إعدادات موجودة في النظام الأصلي.

التفعيل والإلغاء يجب أن يكونا مثل مفتاح تشغيل/إيقاف للواجهة فقط، وليس Migration أو تغييرًا دائمًا في النظام.

شرط الاختبار قبل اعتماد التغيير

قبل اعتماد الإضافة على أي وكيل:

1. تشغيل الوكيل بالتصميم الافتراضي.
2. التأكد من عمل التقارير الحالية.
3. تفعيل التصميم الجديد.
4. اختبار جميع التقارير والبيانات.
5. إلغاء التصميم الجديد.
6. التأكد أن الوكيل عاد إلى نفس الواجهة والسلوك السابقين تمامًا.

الهدف النهائي: يمكن تجربة التصميم الجديد بحرية، وإذا لم يناسب الوكيل يتم إيقافه والعودة للنظام الأصلي بدون فقدان أو تعديل أي بيانات أو تقارير أو وظائف.
