📌 موديل الشات الصوتي والمرئي والاجتماعات داخل نظام ERP (متعدد الشركات)

🎯 الهدف من الموديل

إنشاء نظام تواصل داخلي احترافي داخل الـ ERP يتيح:

- الشات النصي الفوري
- المكالمات الصوتية
- مكالمات الفيديو
- الاجتماعات الجماعية
- مشاركة الشاشة
- دعم فني مباشر للعملاء
- العمل في بيئة متعددة الشركات (Multi-Tenant)

---

🧩 أولاً: هيكل الموديل (Modules Structure)

1. موديل الشات (Chat Module)

الوظائف:

- إرسال واستقبال الرسائل الفورية (Real-Time)
- دعم الرسائل النصية
- إرسال صور / ملفات / فيديوهات
- تسجيل رسائل صوتية
- حالة الرسالة (تم الإرسال - تم الاستلام - تمت القراءة)
- إظهار حالة المستخدم (Online / Offline / Busy)

الجداول:

- Messages
- Conversations
- Attachments
- MessageStatus

---

2. موديل المكالمات الصوتية (Voice Calls)

الوظائف:

- مكالمات صوتية فردية
- دعم جودة صوت عالية
- تسجيل المكالمات (اختياري)
- إشعارات المكالمات الواردة

التقنيات المقترحة:

- WebRTC
- Socket.io

---

3. موديل الفيديو (Video Calls)

الوظائف:

- مكالمات فيديو فردية
- تشغيل/إيقاف الكاميرا
- كتم الصوت
- تغيير جودة الفيديو حسب سرعة الإنترنت

---

4. موديل الاجتماعات (Meetings Module)

الوظائف:

- إنشاء اجتماع جديد
- تحديد:
  - عنوان الاجتماع
  - الوقت والتاريخ
  - المشاركين
- رابط دخول مباشر للاجتماع
- دعم عدد كبير من المستخدمين
- تسجيل الاجتماعات
- مشاركة الشاشة
- Chat داخل الاجتماع

الجداول:

- Meetings
- MeetingParticipants
- MeetingLogs

---

5. مشاركة الشاشة (Screen Sharing)

الوظائف:

- مشاركة شاشة المستخدم
- دعم الدعم الفني لشرح النظام
- تحديد نافذة معينة أو الشاشة بالكامل

---

6. لوحة الدعم الفني (Support Panel)

الوظائف:

- بدء جلسة دعم مباشر مع العميل
- عرض شاشة العميل (بموافقته)
- إرسال ملفات تعليمية
- تسجيل الجلسة
- تقييم الدعم بعد الانتهاء

---

🏢 ثانياً: دعم تعدد الشركات (Multi-Tenant)

الفكرة:

كل شركة لها:

- مستخدمين خاصين
- شات داخلي خاص
- اجتماعات خاصة

التطبيق:

- كل سجل يحتوي على:
  - CompanyID

التحكم:

- منع التواصل بين شركات مختلفة (إلا إذا سمح الأدمن)

---

🔐 ثالثاً: الصلاحيات (Permissions)

إضافة في شاشات:

- صلاحيات المستخدمين
- صلاحيات السوبر أدمن

الصلاحيات:

- استخدام الشات
- بدء مكالمة صوتية
- بدء مكالمة فيديو
- إنشاء اجتماع
- تسجيل الاجتماعات
- مشاركة الشاشة
- الوصول للدعم الفني

---

🖥️ رابعاً: واجهات المستخدم (UI Screens)

1. شاشة الشات

- قائمة المستخدمين
- نافذة المحادثة
- إرسال ملفات
- تسجيل صوت

2. شاشة المكالمات

- زر اتصال صوتي
- زر اتصال فيديو
- عرض حالة الاتصال

3. شاشة الاجتماعات

- قائمة الاجتماعات
- زر "إنشاء اجتماع"
- دخول الاجتماع
- عرض المشاركين

4. شاشة الدعم الفني

- طلب دعم
- انتظار الرد
- بدء جلسة مباشرة
