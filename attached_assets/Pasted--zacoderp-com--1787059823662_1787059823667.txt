يكون معاها لوحه التحكم سوبر ادمن 
طبعا تضيف تابه يسار البيانات هنضيف فيها اسم مستخدم وكلمه المرور سوبر ادمن ونضيف الايميل الهيترسل إليه otp الخاص بتسجيل الدخول نفس نظام المرفوع علي replit كمان ممكن نضيف لينكات الخاصه بالربط مع حساب github.com علشان برنامج الويندوز ابليكشن 
كمان نضيف مكان لاضافه ربط حساب الموبايل ابليكشن تطبيقات الموبايل طبعا كل ده اختيار بس جرد ما مندخل للبيانات صح كل حاجه تعمل تمام 
النسخه دي هتكون متكامله وومكن اربط عليها وكلاء نفس النسخه الحاليه zacoderp.com
فاهمني طبعا 
طبعا وتضيف مكان لربط اي من الوكلاء الحالين بالسيرفر الجديد يعني بعد تجهيز السيرفر لو احتاجت الي تحويل اي من الوكلاء علي السيرفرات الجديد اعرف 
ويتيح ليه في السيرفر الحاله تضيف اداه الي نسخ مثلا البيانات الخاصه ب الوكيل علشان اما أضيفها علي السيرفرات الجديدة يشتغل بشكل كويس 

إضافة وتطوير نظام النشر والتسطيب الذكي (Deployment & Installation)
تطوير شاشة التسطيب الحالية لتصبح منصة نشر متكاملة، بحيث يتم تجهيز السيرفر وتسطيب المشروع وتشغيله بالكامل بشكل آلي دون الحاجة للدخول اليدوي إلى السيرفر.
1. اختيار مصدر المشروع
يتم توفير خيارين فقط:
استخدام Package موجودة حاليًا داخل المنصة.
رفع ملفات مشروع جديدة للمشاريع الخارجية.
وفي حالة اختيار رفع ملفات جديدة يتم رفع:
Backend
Frontend
Database Backup
مع إمكانية اختيار إرسال السورس كامل أو مشفر حسب طبيعة المشروع.
2. اختيار بيئة التشغيل
Linux: VPS / Server.
Windows: VPS أو Web Application عبر IIS.
3. تجهيز السيرفر تلقائيًا
تقوم المنصة بفحص السيرفر وتثبيت وتجهيز جميع المتطلبات المطلوبة حسب المشروع، مثل:
Node.js
TypeScript
React
npm وDependencies
PostgreSQL وقاعدة البيانات
PM2
Nginx على Linux
IIS ومتطلباته على Windows
SSL
إعدادات Environment وConfiguration
الصلاحيات والمنافذ المطلوبة
4. التسطيب والنشر
بعد تجهيز البيئة تقوم المنصة تلقائيًا بـ:
Upload/Package → Database Restore → Backend Deploy → Frontend Deploy → Configuration → Start Services → SSL → Health Check
5. التحديث والنسخ الاحتياطي
قبل أي تحديث يتم إنشاء Backup، مع إمكانية Rollback للنسخة السابقة في حالة حدوث خطأ.
6. التحقق النهائي
بعد انتهاء العملية يتم تنفيذ Health Check للتأكد من:
قاعدة البيانات تعمل.
Backend يعمل.
Frontend يعمل.
الخدمات تعمل بشكل صحيح.
API يستجيب.
الدومين وSSL يعملان.
وفي النهاية تظهر حالة واضحة:
Deployment Successful ✅
أو
Deployment Failed ❌ مع تحديد سبب الخطأ.
وبذلك تصبح الشاشة قادرة على نشر وتسطيب ZacodERP أو أي مشروع خارجي Website / API / Full Stack على Linux أو Windows بالكامل من مكان واحد.
إضافة أداة مركزية لربط وإدارة عدة سيرفرات، بحيث تعمل المنصة الأساسية على أكثر من سيرفر مع توزيع الحمل ومراقبة حالة كل سيرفر. في حال توقف السيرفر الأساسي يتم التحويل تلقائيًا إلى سيرفر بديل دون توقف الخدمة.
يدعم النظام ربط الوكلاء بالسيرفرات المركزية، مع بقاء قاعدة بيانات كل وكيل على سيرفره الخاص، بينما يتم تشغيل الـ Backend والخدمات المركزية من سيرفراتنا. تتم مزامنة السيرفرات المركزية وإدارة التحويل بينها تلقائيًا، مع الحفاظ على أمان البيانات واستقرار النظام الحالي.
