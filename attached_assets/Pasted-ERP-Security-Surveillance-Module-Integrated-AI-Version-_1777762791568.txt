ERP Security & Surveillance Module (Integrated AI Version)

----------------------------------------
🎯 الهدف:
تحويل الموديل من مراقبة فقط → إلى نظام تحكم وربط مع:
- الموارد البشرية HR
- الإنتاج Manufacturing
- المخازن Inventory
- الفروع Branches

----------------------------------------
🧩 أولاً: ربط الموديل بباقي ERP

📌 1) الربط مع HR:

- ربط كل كاميرا بقسم (Department)
- ربط الأحداث بموظف (إن أمكن)

أمثلة:
- موظف غادر مكانه → خصم وقت
- تأخير في الوصول → تسجيل حضور
- جلوس بدون عمل → تقييم أداء

----------------------------------------
📌 2) الربط مع الإنتاج:

- ربط الكاميرات بخطوط الإنتاج

تحليلات:
- زمن التشغيل
- زمن التوقف
- عدد العمال على الخط
- كفاءة الإنتاج

----------------------------------------
📌 3) الربط مع المخازن:

- كاميرات المخزن

تحليلات:
- حركة غير طبيعية
- دخول غير مصرح
- مراجعة الجرد بالكاميرا

----------------------------------------
🏢 ثانياً: دعم الشركات والفروع

- كل سجل مربوط بـ:
  CompanyId
  BranchId

📌 مهم:
كل الأجهزة والكاميرات لازم تكون مربوطة بالفرع

----------------------------------------
🖥️ ثالثاً: تحديث الشاشات الحالية

🔹 شاشة "كل الأحداث":
أضف:
- مصدر الحدث:
  (كاميرا / AI / مستخدم / نظام ERP)

- ربط الحدث بـ:
  - موظف
  - عملية إنتاج
  - مخزن

----------------------------------------
🔹 شاشة "قواعد التنبيهات":

حوّلها إلى:
AI + Business Rules

أمثلة:
- إذا موظف غاب عن الكاميرا > 10 دقائق → تنبيه HR
- إذا خط الإنتاج توقف > 5 دقائق → تنبيه إنتاج
- إذا حركة بالمخزن بعد 10 مساء → تنبيه أمني

----------------------------------------
🖥️ رابعاً: شاشات جديدة

----------------------------------------
📌 1) إدارة الأجهزة (Devices)

- ربط DVR / NVR
- ربط كل جهاز بفرع

----------------------------------------
📌 2) الكاميرات (Cameras)

- ربط الكاميرا بـ:
  - قسم
  - خط إنتاج
  - مخزن

----------------------------------------
📌 3) البث المباشر (Live View)

- مراقبة مباشرة
- اختيار الفرع / القسم

----------------------------------------
📊 خامساً: التقارير (مهم جداً في ERP)

----------------------------------------
📌 تقارير HR:
- تقرير التزام الموظفين
- تقرير وقت التواجد الفعلي
- تقرير السلوك

----------------------------------------
📌 تقارير الإنتاج:
- زمن التوقف
- كفاءة الخط
- عدد العمليات

----------------------------------------
📌 تقارير المخازن:
- النشاط الليلي
- الحركات غير الطبيعية
- مراجعة الكاميرا مع الجرد

----------------------------------------
🔔 سادساً: التنبيهات

- ربط التنبيه بالموديل:
  - HR
  - Production
  - Inventory

📌 مثال:
تنبيه → يفتح Task في ERP تلقائي

----------------------------------------
🧠 سابعاً: الذكاء الاصطناعي داخل ERP

AI مش بس تحليل صورة… لازم يطلع Actions:

- إنشاء Task
- تسجيل مخالفة
- تحديث تقييم موظف
- إيقاف عملية (اختياري)

----------------------------------------
🗂️ ثامناً: تصميم قواعد البيانات

جداول جديدة:

Devices
- Id
- BranchId
- IP
- Status

Cameras
- Id
- DeviceId
- LocationType
- RefId (Employee / ProductionLine / Warehouse)

Events
- Id
- CameraId
- Type
- AIResult
- LinkedModule (HR / Production / Inventory)
- RefId

----------------------------------------
⚙️ تاسعاً: Workflow داخل ERP

📌 السيناريو:

كاميرا → حدث → AI تحليل  
→ تحديد نوع الحدث  
→ ربطه بموديل ERP  
→ تنفيذ Action:

- Alert
- Task
- Report

----------------------------------------
🚀 عاشراً: إضافات احترافية

- Dashboard موحد لكل الفروع
- مقارنة أداء الفروع
- تقييم الموظفين تلقائي
- Heatmap للحركة داخل الفرع

----------------------------------------

✅ موديل داخل ERP مش مجرد كاميرات  
🔥 نظام إدارة ذكي يربط:
الأمان + الموارد البشرية + الإنتاج + المخازن
