[Offers Module - Full Advanced Version]

========================================
[Overview]
========================================
نظام عروض احترافي يدعم:
- ربط العرض بالعملاء (عميل / أكثر / كل العملاء)
- ربط العرض بالأصناف (صنف / أكثر / كل الأصناف)
- ربط العرض بالمناديب (مندوب / أكثر / كل المناديب)

يتم تطبيق العروض تلقائياً داخل الفواتير حسب الشروط.

========================================
[1] Main Fields
========================================

offer_number: رقم العرض (Auto Serial)
customer_scope: (all / specific)
items_scope: (all / specific)
salesrep_scope: (all / specific)
status: (draft / active / expired)
priority: رقم أولوية (1 - 10)
expiry_date: تاريخ انتهاء العرض
created_at: تاريخ الإنشاء

========================================
[2] Customers Logic
========================================

IF customer_scope = specific:
    يتم اختيار عميل أو أكثر (Multi Select)

IF customer_scope = all:
    يتم تطبيق العرض على كل العملاء

========================================
[3] Items Logic
========================================

IF items_scope = specific:
    يتم اختيار صنف أو أكثر (Multi Select)

IF items_scope = all:
    يتم تطبيق العرض على كل الأصناف

========================================
[4] Sales Reps Logic
========================================

IF salesrep_scope = specific:
    يتم اختيار مندوب أو أكثر (Multi Select)

IF salesrep_scope = all:
    يتم تطبيق العرض على كل المناديب

========================================
[6] Invoice Logic (Core Engine)
========================================

INPUT:
- customer_id
- salesrep_id
- items_list

PROCESS:

FOR each offer WHERE status = active:

    IF (customer_scope = all OR customer_id IN offer_customers)
    AND (salesrep_scope = all OR salesrep_id IN offer_salesreps)
    AND (items_scope = all OR item_id IN offer_items)
    AND (expiry_date >= today):

        APPLY offer

========================================
[7] Rules
========================================

- في حالة وجود أكثر من عرض:
    يتم اختيار:
        أعلى priority
        أو أعلى خصم

- لا يتم تطبيق أكثر من عرض على نفس الصنف

- في حالة customer_scope = all:
    يتم تجاهل شرط العملاء

- في حالة items_scope = all:
    يتم تجاهل شرط الأصناف

- في حالة salesrep_scope = all:
    يتم تجاهل شرط المناديب

========================================
[8] Invoice Screen Behavior
========================================

- عند اختيار العميل:
    يتم تحميل العروض المرتبطة

- عند اختيار المندوب:
    يتم فلترة العروض

- عند إضافة صنف:
    يتم فحص العروض تلقائياً

- إضافة زر:
    "تطبيق العروض"

في حالة Specific:

========================================
[10] Performance
========================================

- عمل Index على:
    customer_id
    item_id
    salesrep_id

- Cache:
    تحميل العروض النشطة فقط

========================================
[11] Security & Control
========================================

- منع تعديل العرض بعد تفعيله (active)
- تسجيل Log عند تطبيق العرض
- التحكم في الصلاحيات:
    إنشاء / تعديل / اعتماد / تطبيق

========================================
[12] Important Notes
========================================

- لا يمكن تطبيق عرض بدون وجود عميل في الفاتورة
- العروض العامة يتم تطبيقها بعد اختيار العميل
- يجب تحقق جميع الشروط:
    (العميل + المندوب + الصنف)
