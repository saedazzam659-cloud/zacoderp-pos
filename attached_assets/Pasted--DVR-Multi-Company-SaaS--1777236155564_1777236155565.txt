🚀 منصة الحضور والانصراف بالذكاء الاصطناعي + DVR (Multi-Company SaaS)

---

🎯 الهدف العام

إنشاء نظام مركزي ذكي يعتمد على التعرف على الوجه من خلال DVR/Kameras لتسجيل الحضور والانصراف، مع دعم:

- تعدد الشركات (Multi-Tenant)
- تعدد الفروع
- تعدد الكاميرات
- إدارة مركزية من Super Admin

---

🧠 المفهوم المعماري (Architecture)

1. Multi-Tenant Architecture

- كل شركة = Tenant
- عزل البيانات بالكامل
- دعم:
  - Subdomain لكل شركة (مثال: company1.zacoderp.com)
  - أو TenantID داخل نفس النظام

---

1. الشركات (Companies)

- CompanyID

- Domain
- SubscriptionPlan
- Status

2. الفروع (Branches)

- Code

- CameraID

- ID

- Date

---

🖥️ الشاشات الأساسية

---

1. شاشة Super Admin

- إدارة الشركات
- إدارة الاشتراكات
- مراقبة النظام
- Dashboard عام:
  - عدد الشركات
  - عدد العمليات اليومية
  - أداء الذكاء الاصطناعي

---

2. شاشة إعداد الشركة

- تفعيل AI
- تحديد سياسة الحضور:
  - مرونة الوقت
  - عدد مرات الدخول
- ربط الفروع

---

3. شاشة ربط DVR والكاميرات

- إضافة أكثر من كاميرا
- Live Preview
- Test Connection
- اختيار:
  - نوع الكاميرا
  - بروتوكول RTSP / HTTP

---

4. شاشة تسجيل الوجه (Face Enrollment)

- اختيار الموظف
- التقاط صور متعددة
- تحليل جودة الوجه:
  - إضاءة
  - زاوية
- تخزين Face Encoding

---

5. شاشة الحضور الذكية

- عرض مباشر للكاميرا
- عرض:
  - اسم الموظف
  - صورته
  - نسبة التطابق
- تسجيل تلقائي:
  - حضور
  - انصراف

---

⚙️ محرك الذكاء الاصطناعي (AI Engine)

المكونات:

- Face Detection
- Face Encoding
- Face Matching

آلية العمل:

1. التقاط Frame من DVR
2. كشف الوجه
3. تحويله إلى Encoding
4. مقارنة مع قاعدة البيانات الخاصة بالشركة فقط
5. إرجاع أفضل Match

---

🔄 Workflow احترافي

1. الكاميرا تبث الفيديو
2. خدمة AI تلتقط Frame كل 1-2 ثانية
3. يتم التعرف على الوجه
4. إذا تم التعرف:
   - التحقق من:
     - آخر تسجيل
     - سياسة الشركة
   - تسجيل الحدث
5. إرسال النتيجة:
   - للواجهة مباشرة
   - حفظ في DB
