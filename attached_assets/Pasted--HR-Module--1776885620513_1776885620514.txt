إنشاء موديل شؤون الموظفين (HR Module) - موجه للسوق السعودي

الهدف:
بناء نظام متكامل لإدارة شؤون الموظفين متوافق مع متطلبات السوق السعودي، مع التركيز على إدارة العقود، الإقامات، والتنبيهات التلقائية.

----------------------------------------

1. إدارة الموظفين (Employees Management)

شاشة إضافة / تعديل موظف:
- كود الموظف (Auto / Manual)
- الاسم (عربي / إنجليزي)
- رقم الهوية / الإقامة
- تاريخ انتهاء الإقامة
- الجنسية
- رقم الجوال
- البريد الإلكتروني
- تاريخ التعيين
- القسم / الوظيفة
- الفرع / الشركة
- الحالة (نشط / موقوف / خروج نهائي / إجازة)
- صورة الموظف
- ملاحظات

خصائص:
- منع تكرار رقم الهوية / الإقامة
- تنبيه قبل انتهاء الإقامة (30 / 60 / 90 يوم)
- Dashboard لعرض الإقامات التي قاربت على الانتهاء

----------------------------------------

2. إدارة العقود (Contracts Management)

شاشة إضافة عقد:
- رقم العقد
- الموظف
- نوع العقد (محدد المدة / غير محدد)
- تاريخ بداية العقد
- تاريخ نهاية العقد
- الراتب الأساسي
- البدلات
- شروط العقد
- حالة العقد (ساري / منتهي / مجدد)

خصائص:
- تنبيه تلقائي قبل انتهاء العقد
- إمكانية تجديد العقد بضغطة زر مع حفظ النسخة السابقة
- أرشفة العقود القديمة

----------------------------------------

3. الإقامات والتأشيرات (Iqama & Visa Tracking)

- رقم الإقامة
- تاريخ الإصدار
- تاريخ الانتهاء
- المهنة
- الكفيل
- حالة الإقامة

خصائص:
- تنبيهات تلقائية قبل الانتهاء
- تقارير بالإقامات المنتهية أو القريبة من الانتهاء
- ربط الإقامة بالموظف مباشرة

----------------------------------------

4. الرواتب (Payroll)

- الراتب الأساسي
- بدل سكن
- بدل انتقال
- إضافي
- خصومات (تأمينات / سلف / جزاءات)
- صافي الراتب

خصائص:
- توافق مع نظام الأجور (WPS إن لزم)
- تحويل الرواتب للبنوك
- ربط محاسبي تلقائي

----------------------------------------

5. الحضور والانصراف (Attendance)

- تسجيل حضور / انصراف
- عدد ساعات العمل
- التأخير
- العمل الإضافي

خصائص:
- ربط جهاز البصمة (اختياري)
- تقارير شهرية

----------------------------------------

6. الإجازات (Leaves)

- طلب إجازة
- نوع الإجازة
- مدة الإجازة
- اعتماد المدير

خصائص:
- حساب الرصيد تلقائيًا
- خصم من الراتب عند الحاجة

----------------------------------------

7. التنبيهات (Alerts & Notifications)

نظام تنبيهات مركزي يشمل:
- تنبيه انتهاء الإقامة
- تنبيه انتهاء العقد
- تنبيه انتهاء جواز السفر (اختياري)
- تنبيه تجديد الوثائق

طرق التنبيه:
- داخل النظام (Dashboard)
- بريد إلكتروني
- إشعارات

----------------------------------------

8. التقارير (Reports)

- تقرير الموظفين
- تقرير الإقامات
- تقرير العقود
- تقرير الرواتب
- تقرير التنبيهات

----------------------------------------

9. الصلاحيات (Permissions)

- ربط المستخدم بالشركة والفرع
- تحديد صلاحيات كاملة (CRUD)
- عزل بيانات كل شركة عن الأخرى

----------------------------------------

10. اعتبارات مهمة للسوق السعودي

- دعم اللغة العربية بالكامل
- توافق مع قوانين العمل السعودية
- إدارة الكفالة
- متابعة الإقامات والتجديدات
- مرونة في إدارة العقود

----------------------------------------

11. تحسينات مستقبلية

- ربط منصة أبشر / مقيم (API)
- إدارة تقييم الأداء
- بوابة موظف (Employee Self Service)
- تطبيق موبايل
