مراحل تنفيذ Zacod — Instance العميل مع API مركزي
تجهيز Zacod المركزي
React Frontend.
Node.js + TypeScript Backend.
PostgreSQL.
API مركزي على: api.zacoderp.com
نظام License وInstallation لكل وكيل.
تجهيز Instance العميل
تثبيت React Production Build فقط على سيرفر العميل.
لا يتم إرسال Source Code الأصلي.
لا يحتاج العميل إلى Backend كامل.
ربط الـ Frontend بـ API المركزي.
تسجيل الـ Instance من لوحة SuperAdmin:
إنشاء Agent ID.
إنشاء Installation ID.
تسجيل Domain/Subdomain.
إنشاء License.
تحديد Database الخاصة بالوكيل.
ربط قاعدة البيانات
العميل يجهز PostgreSQL على سيرفره.
يتم إنشاء Database مستقلة للوكيل.
يتم إعطاء Zacod طريقة اتصال آمنة بها.
يتم اختبار الاتصال من النظام.
تسجيل الدخول المستخدم يدخل من Domain العميل:
Domain → React → api.zacoderp.com → التحقق من License + Domain + Installation → تحديد Company Code → الاتصال بقاعدة بيانات الوكيل → تسجيل الدخول.
تشغيل النظام الـ React عند العميل يعرض النظام، بينما العمليات الأساسية تتم من خلال API المركزي عند Zacod.
التحديثات عند تطوير Zacod:
تطوير → Build → Publish API/Backend → التحديث يظهر فوراً لجميع الوكلاء.
أما تحديث React: → يتم نشر Build جديد → الـ Instance عند العميل تسحب الإصدار الجديد أو يتم تحديثها مركزياً.
Database Migration عند وجود تعديل في قاعدة البيانات:
إنشاء Migration Version.
تحديد الوكلاء المطلوب تحديثهم.
تنفيذ Migration على Database كل وكيل.
تسجيل Database Version.
عدم التأثير على قواعد الوكلاء الآخرين.
